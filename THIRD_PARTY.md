# Third-party source and references

## AROS AmigaGuide datatype

This project uses the AROS AmigaGuide datatype as a reference implementation for AmigaGuide syntax and behavior.

AROS is the AROS Research Operating System, maintained by the AROS development team:
https://github.com/aros-development-team/AROS

The AROS source is distributed under the **AROS Public License (APL) Version 1.1**. See the upstream `LICENSE` file for the complete terms.

Attribution is especially important for any AROS source that is copied or modified into this project. The AROS project notes that accurate attribution of upstream development is required by the APL.

Where this project independently reimplements behavior, the AROS implementation remains a reference rather than a source dependency.
